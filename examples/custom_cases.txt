// Custom cases. Copy this file to csgo_gc/custom_cases.txt in your game folder to use it.
//
// Two kinds of block:
//
//   ADD a new case: the block's name is any word you like, and "based_on" is the def
//   index of an existing case to copy the look and key from. The new case appears next
//   to the originals, which stay as they are. It is listed first in the shop (see
//   star_shop in config.txt) and its contents preview shows its own skins. The game's
//   items_game.txt is edited to add it (restart the game twice the first time).
//       "my_case"
//       {
//           "based_on"  "4001"
//           "name"      "My Case"
//           ...
//       }
//
//   REPLACE an existing case: the block's name is the def index of that case. Opening
//   it rolls from the lists below instead. Pick an old case you don't care about.
//       "4001"
//       {
//           ...
//       }
//
// "name" (optional) is shown on the case like a name tag, e.g. "Galaxy Case".
// A replaced case's contents preview (inspecting the case) comes from the game's own
// files, so it shows the original skins unless you turn on "custom_case_previews" in
// config.txt (experimental, edits items_game.txt with a backup). An added case always
// shows its own skins.
//
// Items are written like the game's loot lists: "[paint_kit_name]weapon_name".
// Any paint kit can go on any weapon, including unused/unreleased paint kits,
// as long as the name exists in csgo/scripts/items/items_game.txt ("paint_kits").
//
// "items": the value is the rarity the skin should roll as:
//     common, uncommon, rare, mythical, legendary, ancient (covert)
//   leave it empty ("") to use the paint kit's own rarity.
// "golds": knives/gloves (rolled at the gold rate; the case pity system applies).
//
// Which finishes look right on other weapons? Rough rule by paint kit prefix:
//   aa_ (fades), am_ (anodized multicolor), an_ (anodized), so_ (solid),
//   hy_ (hydrographic), sp_ (spray) are generic and usually fine anywhere.
//   cu_ (custom paint) and gs_ (gunsmith) are painted for one weapon's model
//   and usually look scrambled on anything else.
//   aq_ (patina) and am_ kits with drawn artwork (e.g. Kumicho Dragon, Cartel)
//   can sit oddly; abstract ones (galaxy, gold brick, quartz) look best.
// Unknown names are skipped with a message in the console. Try new combos with
// the RCON give command and inspect them before putting them in a case.
//
// Odds per rarity come from "rarity_weights" in config.txt, same as real cases.
// Like real cases, 1 in 10 unboxes is StatTrak (gloves never are).
