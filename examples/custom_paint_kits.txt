// Custom finishes. Copy this file to csgo_gc/custom_paint_kits.txt in your game folder.
//
// These are the Sporty and Specialist glove finishes from the unused ("concept") gloves mod; the rest of that mod rendered black or chrome in game, so they were dropped. For each one:
//   1. put its .vmt in   csgo/materials/models/weapons/customization/paints_gloves/
//      (that is all: the .vmt only sets colours on textures the game already has, so there is nothing
//      to convert; the mod's .png/.jpg pictures are previews and aren't used)
//   2. restart the game twice (the first start adds the finishes to items_game.txt)
// A finish without its .vmt shows as a missing-texture checkerboard in game.
//
// Finish names: the game shows a finish's name from its language file, which lives inside the game's VPK.
// To see the "title" of each finish instead of a blank name, extract resource/csgo_english.txt from
// pak01_dir.vpk into csgo/resource/ (so csgo/resource/csgo_english.txt exists), then restart twice.
// The GC adds the names to it and keeps a backup next to it (.csgo_gc_backup).
//
// One block per finish, named after the finish. Every key is optional except what the finish needs:
//   "id"      a number; picked from the name when missing
//   "title"   the name shown in game
//   "rarity"  common, uncommon, rare, mythical, legendary, ancient (default ancient)
//   other keys are copied into the game's items_game.txt paint_kits entry, e.g. "vmt_path" for a
//   glove material, or "style", "pattern", "color0".. for a finish painted on weapons
// Use them in custom_cases.txt like any finish: "[sporty_red]sporty_gloves"
